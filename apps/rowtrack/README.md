# RowTrack

Rowing workout tracker voor iOS en Android. Verbindt live met een roeitrainer via Bluetooth (FTMS-protocol); ontwikkeld tegen een Fluid Rower Apollo XL.

## Tech Stack

- **Expo** (React Native) met TypeScript
- **Expo Router** voor navigatie
- **react-native-ble-plx** voor Bluetooth / FTMS
- **Supabase** voor database en authenticatie
- **Storybook** (`react-native-web-vite`) voor de componentlaag in de browser

Geen Tailwind en geen NativeWind: de rollaag komt uit `constants/`, gegenereerd uit de design tokens. Zie `CLAUDE.md` → *Design-systeem-bron*.

## Aan de slag

Dit is een pnpm-workspace; installeer vanaf de repo-root.

```bash
pnpm install
pnpm dev:rowtrack
```

Maak `apps/rowtrack/.env` aan:

```
EXPO_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
EXPO_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
```

Zonder deze twee gooit `lib/supabase.ts` bij het laden — dat is opzet, geen bug.

## Database

`supabase/schema.sql` is een **historische snapshot en geen opbouwpad**: hij mist de kolommen die de twaalf bestanden in `supabase/migrations/` sindsdien toevoegen, twee kolommen die de app leest (`is_pr`, `max_spm`) staan in geen enkel DDL-bestand, en `add_workout_goals.sql` botst met wat `schema.sql` al aanmaakt. Een verse database ermee opzetten levert een schema waarop de app niet draait.

Lees het werkelijke schema live via de `supabase-rowtrack` MCP-server (`list_tables`). Het opnieuw uitvoerbaar maken van de DDL staat als open item in `BACKLOG.md`.

## Design tokens

`tokens/` bevat de design tokens in Tokens Studio-formaat, bidirectioneel gesynct met Figma. Dat is de **bron**.

`constants/` is de **gegenereerde output** (`pnpm --filter rowtrack tokens:build`, Style Dictionary). Elk bestand daar begint met `// Auto-generated by Style Dictionary — do not edit manually`; een handmatige wijziging overleeft de eerstvolgende build niet. Importeer eruit, bewerk het niet.

## Verifiëren

```bash
pnpm --filter rowtrack type-check      # tsc --noEmit
pnpm --filter rowtrack test            # node:test, de rekenkundige en concurrency-invarianten
pnpm --filter rowtrack build-storybook && pnpm --filter rowtrack render:sweep
```

De volledige tabel met wat er per capability te meten valt — Figma-parity, beeldvergelijking, flow-doorloop, toestel-schuld — staat in `CLAUDE.md` → *Verify-pad*.

## Mapstructuur

```
app/          — Schermen en navigatie (Expo Router)
components/   — Herbruikbare UI-componenten, met stories
constants/    — Gegenereerde design tokens (kleuren, typografie, spacing)
i18n/         — Alle user-facing tekst (NL); zie i18n/translations/nl.ts
lib/          — Supabase-client, auth, BLE-diensten, hooks, rekenlogica
types/        — Gedeelde types en module-augmentaties
tokens/       — Tokens Studio JSON, bron voor constants/
supabase/     — Schema, migraties, seed en de delete-account Edge Function
scripts/      — Meet- en guard-scripts (Figma-parity, render-sweep, beeldvergelijking)
figma/        — Bouwspec, manifest en de builder voor de Figma-keten
audits/       — Audits en reviews
briefings/    — TC-EBC-briefings per feature of scherm
```
