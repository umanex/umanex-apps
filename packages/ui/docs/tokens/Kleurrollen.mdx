# Kleurrollen

Elke rol bestaat in beide modes; de build faalt op asymmetrie. De referentie achter het
kleurvlak is de primitive uit `tokens.json`, de kleur zelf is de waarde die `theme.css` levert.
Een `x-foreground`-rol is de tekstkleur die op `x` hoort.
